# RobotGo v1.0.1

A compatible patch release of `github.com/marang/robotgo`, containing the
reviewed upstream compatibility fixes and native Wayland capture hardening
merged after v1.0.0. Exported signatures, backend selection, agent schemas and
the [v1 runtime support scope](../compatibility/runtime-v1.md) remain unchanged.
The public `Version` constant becomes `v1.0.1`.

## Install

Go 1.26 or newer and the documented platform dependencies are required.

```bash
go get github.com/marang/robotgo@v1.0.1
```

## Fixes

- Windows native input supplies physical scan metadata and distinguishes E0
  extended keys without incorrectly marking Pause as extended. Explicit
  modifier sides satisfy implicit generic modifiers without duplicate holds;
  numpad Clear mapping and unsupported non-BMP validation are corrected.
- Native Wayland capture normalizes inverted rows after logical cropping and
  validates dimensions, strides, byte sizes and allocation arithmetic before
  copy. SHM mappings retain their actual mapped length, selected backends ignore
  unselected offers, duplicate offers fail explicitly, and failure paths clean
  owned buffers, mappings and descriptors.
- Native Wayland and portal horizontal scrolling now share the public
  positive-left direction contract. Low-level protocol semantics are unchanged.

Implementation and regression evidence: [PR #169](https://github.com/marang/robotgo/pull/169)
and [PR #170](https://github.com/marang/robotgo/pull/170).

## Qualification and limits

Patch maintenance does not reopen the first-stable RC observation interval.
Current-head review, complete CI and fresh exact-source evidence remain required:
a successful manual run on the final merged source, followed by the exact-tag
release run, six native/Pure-Go snapshots and all 29 required checks. Verify the
published archive/checksum pair and matching commit/tree/ref/run identities as
described in [Release Evidence v1](../compatibility/release-evidence-v1.md):

```bash
sha256sum -c robotgo-release-evidence-v1.0.1-*.tar.gz.sha256
go list -m -f '{{.Version}}' github.com/marang/robotgo@latest
GOPROXY=direct go list -m -f '{{.Version}}' github.com/marang/robotgo@latest
```

Both module resolutions must report `v1.0.1`; proxies may first need to index the
explicit version. Existing v1.0.0, RC and beta tags/assets remain immutable.
Rollback means pinning `github.com/marang/robotgo@v1.0.0`, never moving a tag.

Permission-granted macOS runtime evidence remains externally blocked under
[LAB-69](https://linear.app/riotbox/issue/LAB-69); this release adds no permission
or compositor support claims. The CGO scale-resource cleanup
[LAB-238](https://linear.app/riotbox/issue/LAB-238) and legacy CGO/strict-API
decomposition [LAB-71](https://linear.app/riotbox/issue/LAB-71) are subsequent,
separate maintenance work, not included here.
