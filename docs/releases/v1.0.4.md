# RobotGo v1.0.4

Prepared release; publication and retained qualification gates are pending.

The canonical module changes to `go.izoone.com/robotgo`. Migrate root and
subpackage imports together; the root layout remains v1 without `/v2`.
Existing GitHub module versions, historical v2 beta tags and release assets
remain immutable. The compatibility baselines change the owned module
prefix and the `Version` release-metadata value; public declarations, JSON contracts and third-party identities retain
their existing behavior. Dependencies, including imgo `v0.44.0` and its image
compatibility protection, are unchanged.

The build-only module packager creates standard immutable `.info`, `.mod` and
`.zip` artifacts from committed source. This does not install a publisher or
establish native platform or public consumer qualification. See the
[distribution contract](../operations/module-distribution.md) for remaining
release integration and acceptance gates.
