# RobotGo v1.0.2

A compatible maintenance release of `github.com/marang/robotgo`. It releases
native scale-query resources, separates internal CGO ownership and policy, and
refreshes dependencies. Exported signatures, backend selection, legacy image
representation, agent schemas and the [v1 runtime support scope](../compatibility/runtime-v1.md)
remain unchanged. The public `Version` constant becomes `v1.0.2`.

## Install

Go 1.26.10 or newer and the documented platform dependencies are required.

```bash
go get github.com/marang/robotgo@v1.0.2
```

## Changes

- macOS scale queries release copied display modes, and Windows scale queries
  release desktop device contexts, including invalid-result paths. Existing
  display selection and scale failure behavior are preserved ([#172](https://github.com/marang/robotgo/pull/172)).
- CGO facades delegate to focused policy and ownership modules while preserving
  the frozen public API and legacy sequencing ([#173](https://github.com/marang/robotgo/pull/173)).
- Updated dependencies, automated dependency monitoring and vulnerability checks;
  CI uses the patched Go version declared in `go.mod`. `imgo` remains at 0.42.0
  to preserve JPEG, Base64 and padding compatibility ([#175](https://github.com/marang/robotgo/pull/175)).

## Qualification and limits

Publication requires current-head review and CI, a successful manual Release
evidence run on the final merged source, and an exact-tag run containing six
native/Pure-Go snapshots and all 29 required checks. Verify the public assets
and their commit, tree, ref and run identities using [Release Evidence v1](../compatibility/release-evidence-v1.md):

```bash
sha256sum -c robotgo-release-evidence-v1.0.2-*.tar.gz.sha256
go list -m -f '{{.Version}}' github.com/marang/robotgo@latest
GOPROXY=direct go list -m -f '{{.Version}}' github.com/marang/robotgo@latest
```

Both module resolutions must report `v1.0.2`; proxies may need to index the
explicit version first. Rollback means pinning `v1.0.1`. Historical tags and
assets remain immutable. Permission-granted macOS runtime evidence remains
externally blocked under [LAB-69](https://linear.app/riotbox/issue/LAB-69);
this release adds no permission or compositor support claims.
